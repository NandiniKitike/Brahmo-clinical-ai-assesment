# Prompt Library

This directory contains the exact prompts used during the AI-first development of this project, as required by the Assessment Brief.

## Directories
- `normalization/`: Prompts used for dataset mapping and normalisation.
- `fdc_decomposition/`: Prompts used to extract salts from FDC strings.

*Note: The system itself uses zero-shot deterministic prompts which are loaded dynamically in the code.*
